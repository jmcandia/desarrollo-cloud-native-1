# Capítulo 3: Desarrollando soluciones con streaming de datos

En este capítulo aprenderemos cómo trabajar con **flujos de datos y eventos** que se generan y procesan de manera continua. Conoceremos los fundamentos del streaming, exploraremos cómo distribuir y consumir grandes volúmenes de información y veremos cómo este enfoque nos permite construir soluciones escalables y capaces de procesar datos en tiempo real o cercano al tiempo real. A través de ejemplos prácticos, aplicaremos estos conceptos para comprender cuándo y por qué utilizar arquitecturas basadas en streaming.
