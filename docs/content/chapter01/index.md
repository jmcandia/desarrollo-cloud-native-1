# Capítulo 1: Configurando API Manager e Identity as a Service

En este capítulo aprenderemos cómo gestionar y proteger las APIs que permiten la comunicación entre nuestras aplicaciones y servicios. Conoceremos el papel de un **API Manager** y de las soluciones de **Identity as a Service (IDaaS)**, y veremos cómo integrarlos para controlar el acceso a nuestros recursos. A través de **OAuth 2.0** y **OpenID Connect**, implementaremos mecanismos de autenticación y autorización que nos permitirán construir aplicaciones más seguras y preparadas para entornos Cloud Native.
